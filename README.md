# One-Line Roast: The Gadget You Use Every Day

One original one-line roast of the phone everyone unlocks a hundred times a
day: Face ID knows your face instantly, yet the phone still demands the
password every morning — apparently even it doesn't trust you before coffee.
A specific, everyday gripe with a concrete detail and a sting at the end,
in 116 characters.

## Run it

```sh
python3 main.py
```

Writes the roast to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt`
when the variable is unset). Python 3.13, standard library only, no network,
fully deterministic.
